# 영상의 빈틈을 찾는 AI 배리어프리 점검 도구


## Problem
공공기관 영상 편집자는 시청각장애인이 보는 안내 영상을 만들 때, 음성·자막·화면 글자가 같은 정보를 빠짐없이 전달하는지 사람이 직접 비교해 검수한다. 정보가 자막에만 있거나 음성으로만 있으면 특정 장애를 가진 시청자는 그 정보를 받지 못하고, 사람이 하는 검수는 시간이 오래 걸리며 실수(human error)도 생긴다. 음성·자막·화면 정보를 교차 점검해 주는 수단이 없어서 이 작업은 전부 수작업이다.


## Evidence
- Assumption — needs validation via user research (공공기관 영상 편집자 인터뷰, 라운드테이블 자문으로 현재 검수 소요 시간과 실제 누락 사례 확인)
- 문제가 생기는 구조: 음성으로 안내한 내용이 자막에서 빠지거나, 화면에만 표시된 정보가 음성으로 설명되지 않는다. 교차 검토를 하지 않으면 제작 중 발견하기 어렵다. (팀 신청 문서 기술이며, 현장 데이터는 아니다.)


## Users
- **Primary**: 공공기관에서 시청각장애인이 시청하는 안내 영상(행사, 복지서비스, 시설 이용 안내 등)을 제작·편집하는 영상 편집자. 배포 전 접근성 검수가 필요할 때 이 도구를 쓴다.
- **Not for**: 지역미디어센터 등 공공기관 밖의 제작자, 영상 시청자(장애인 당사자) 본인, 접근성 전문 검수 업체.


## Hypothesis
We believe **영상의 음성·자막·화면 글자를 AI가 교차 비교해 정보 누락·불일치 구간을 표시해 주는 점검 도구**가 **사람이 직접 하던 검수 시간을 줄이고 사람 실수로 놓치는 누락을 줄여 줄 것**이라고 믿는다. 대상은 **공공기관 영상 편집자**이다.
We'll know we're right when **같은 영상의 검수 시간이 수작업 대비 50% 이상 줄고, 사람이 확인한 실제 누락의 80% 이상을 도구가 짚어 낸다.**

## Scope
**MVP** — 영상(필요 시 자막 파일 포함)을 입력하면 다음을 점검하고 구간별로 확인할 수 있다.
1. 음성과 자막을 비교해 자막 누락·내용 불일치 구간을 표시한다.
2. 화면 글자와 음성을 비교해 화면에만 있고 음성으로 안내되지 않은 중요한 정보를 표시한다.
3. 점검 결과를 구간별로 확인한다. 도구가 짚은 항목은 편집자가 실제 문제인지 판단해 확정한다(사람 확인 단계).


**Out of scope**
- 영상 길이는 20분으로 제한
- 영상 업로드는 1건씩만 처리한다.
