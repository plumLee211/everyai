# 배리어프리 영상 AI 점검 도구 | 화면 기획 초안 v0.3

> **용도:** PPT·Figma 화면 설계를 위한 간단한 기능 정의  
> **기준:** 개발 Plan(M1~M3) 및 확정된 화면 구성 방향

## 1. 서비스 개요

영상 편집자가 **영상과 자막을 등록**하면, AI가 음성·자막·화면 속 글자를 비교해 **검토가 필요한 구간**을 찾아준다. 편집자는 원본 영상을 확인하고 문제를 **확정 또는 기각**한 뒤 결과를 내보낸다.

- **대상:** 공공기관 영상 제작·편집 및 접근성 검수 담당자
- **형태:** Windows 데스크톱 프로그램 / 영상 1건씩 분석(최대 20분)
- **검토 범위:** 음성↔자막 누락·불일치(M1), 화면의 주요 문자 정보↔음성 전달 여부(M2)
- **기본 원칙:** AI는 검수할 구간을 제안하며, 최종 판단은 사용자가 한다.

## 2. 핵심 기능 정의

| 기능 | 설명 |
|---|---|
| 영상·자막 등록 | 영상 1개와 자막 파일(선택)을 등록한다. |
| 자막 자동 추출 | 자막 파일이 없으면 영상 속 자막을 OCR로 추출한다. 자막 자체가 없으면 자막 부재를 안내한다. |
| 음성·자막 점검 (M1) | 발화와 자막을 비교해 누락·불일치 의심 구간을 찾는다. |
| 화면 문자 점검 (M2) | 화면에 표시된 날짜·시간·금액·연락처 등 주요 정보가 음성으로 전달되는지 확인한다. |
| 분석 진행 확인 | 진행 단계와 상태를 보여주고 분석 취소를 지원한다. |
| 구간별 검수 (M3) | 문제 목록을 선택해 해당 영상을 확인하고 **미검토 / 확정 / 기각**으로 관리한다. |
| 결과 정리 | 탐지·검수 건수를 요약하고 CSV로 내보낸다. |
| 분석 설정 | PC 사양에 맞는 권장 모델을 기본 적용하고, 고급 설정에서 모델과 OCR 자막 영역을 조정한다. |

## 3. 화면 구성

| ID | 화면 | 주요 구성 요소 | 사용자 동작 |
|---|---|---|---|
| **01** | **영상 등록** | 영상 선택, 자막 선택(선택), 파일 정보, 자막 처리 안내, 분석 시작 | 파일을 등록하고 분석 시작 |
| **02** | **분석 진행** | 분석 단계, 진행 상태, 분석 취소 | 진행 상황 확인 또는 취소 |
| **03** | **검수 작업** | 상단 요약, **좌측 영상 플레이어**, **우측 문제 목록**, **하단 문제 상세·음성/문자 비교**, 확정·기각, CSV 내보내기 | 목록 선택 → 영상 확인 → 확정·기각 → 내보내기 |
| **04** | **분석 설정** *(팝업)* | PC 사양, 권장 모델, 고급 설정(모델 선택·OCR 영역 조정) | 필요할 때 기본 설정 변경 |

### 검수 화면(03) 배치

```text
┌──────────────────────────────────────────────────────────┐
│ 영상명 · 탐지 수 · 미검토 수 · 확정 수 · 기각 수 · 내보내기 │
├──────────────────────────────┬───────────────────────────┤
│                              │                           │
│       영상 플레이어          │      문제 목록            │
│       재생 / 시간 이동       │      유형·상태별 확인     │
│                              │                           │
├──────────────────────────────┴───────────────────────────┤
│ 문제 상세: 발생 구간 · 탐지 이유 · 음성/자막(화면 문자) │
│                                   [기각]     [확정]      │
└──────────────────────────────────────────────────────────┘
```

## 4. 기본 사용 흐름

**영상·자막 선택 → 분석 시작 → 진행 상태 확인 → 문제 목록 검수 → 결과 내보내기**

- 자막 파일 **있음**: 등록한 자막으로 점검
- 자막 파일 **없음**: 기본적으로 **화면 하단 25%**를 자막 후보 영역으로 인식, 설정에서 조정 가능
- 자막 자체가 **없음**: 개별 누락 문제를 쏟아내지 않고 자막 부재 안내

## 5. 화면 설계 시 유의사항

- 분석 결과는 **오류 확정**이 아닌 **검토 필요**로 표현한다.
- 결과가 0건이어도 접근성 기준 전체를 충족했다고 표현하지 않는다.
- 설정은 **권장값 기본 적용 / 고급 옵션 숨김**으로 단순하게 유지한다.
- 이번 범위에서 **영상·자막 직접 편집, TTS 생성, 몸짓·장면 분석, 효과음 분석**은 제외한다.
