# 실증 진행자 확인 목록

참가자에게 [`participant-guide.md`](participant-guide.md)와 [`record-sheet.csv`](record-sheet.csv)를 주기 전에 확인한다. **확인하지 않은 항목은 비워 둔다.** Windows 설치와 빌드의 확인 목록은 [`build/README.md`](../../../build/README.md)에 있다.

## 배포본
- [ ] 배포할 커밋의 CI가 통과했다. 커밋 번호:
- [ ] 앱 버전(`barrierfree.__version__`)과 규칙 버전(`config.RULES_VERSION`)을 기록했다.
- [ ] 설치 파일에 `base`, `small`, `medium` 모델과 EasyOCR 모델이 들어 있다.
- [ ] 실제 Windows PC에서 `build/README.md`의 확인 목록을 통과했다. PC 사양:
- [ ] **네트워크를 끊고** 설치와 첫 분석이 된다.
- [ ] 20분 영상의 처리 시간과 최대 메모리를 기록했다. 시간:　　 메모리:
- [ ] 이전에 배포한 `v0.1.x`의 분석 기록이 있는 PC에서 새 버전이 기록을 열고, 사본 위치를 알린다. 올린 기록은 `v0.1.x`에서 열 수 없다. 시험한 이전 버전:
- [ ] [점검 범위]의 문구가 이 버전의 실제 동작과 맞다.

## 분석 확인(직접 눈으로)
- [ ] 자막 파일이 있는 경우와 없는 경우를 각각 분석했다.
- [ ] 대조 보기에서 시각을 누르면 영상이 이동하고, `지적 n`을 누르면 그 지적이 열린다.
- [ ] 지표 CSV에 영상의 내용, 파일 이름, 경로가 없는지 열어 확인했다.

## 참가자와 자료
- [ ] 영상의 이용 권한과 수집할 파일, 보관 기간, 삭제 방법을 정하고 동의를 받았다.
- [ ] 참가자 PC의 이전 앱 데이터를 어떻게 할지 정했다.
