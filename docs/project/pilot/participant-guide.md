# 실증 참가 안내

이 앱은 영상의 음성, 화면 글자, 자막을 대조해 **사람이 확인할 곳**을 알려 주는 도구입니다. 접근성 점검을 대신하지 않으며, 실증 중의 결과를 실제 업무의 판단에 그대로 쓰지 않습니다.

## 시작하기 전에
- 사용할 영상은 **분석하고 자료를 남겨도 되는 영상**만 씁니다. 20분 이하여야 합니다.
- 영상은 이 컴퓨터에서 분석하며 앱이 영상이나 결과를 밖으로 보내지 않습니다. **설치 파일에 포함된 모델(`base`, `small`, `medium`)을 쓰면 인터넷 없이 분석합니다.** 설정에서 다른 모델을 고르거나 모델 폴더를 직접 지정했는데 그 안에 모델이 없으면, 모델을 내려받으려고 인터넷에 접속할 수 있습니다.
- 음성 인식 모델은 설정의 **"권장 모델 사용 (small)"**을 그대로 둡니다. 메모리 경고가 나타나 모델을 바꿨다면 기록지에 적어 주세요.
- 분석한 내용(음성 인식 결과, 화면 글자, 지적)은 **이 컴퓨터의 앱 데이터 폴더에 저장됩니다.** 이전에 이 앱을 썼다면 처음 실행할 때 기록의 구조가 바뀌며, 바꾼 기록은 이전 버전의 앱에서 열 수 없습니다. 바꾸기 전 사본의 위치를 앱이 알려 줍니다.

## 앱에서 알아 둘 것
- 분석 후 검수 화면의 **[점검 범위]**를 먼저 읽어 주세요. 도구가 점검하지 않거나 놓칠 수 있는 것이 있습니다.
- **"지적이 없다"는 문제가 없다는 뜻이 아닙니다.**
- **문제 목록:** `문제 의심`, `검수 필요`, `판단 불가`는 앱의 추정입니다. 직접 확인하고 [확정] 또는 [기각]을 누릅니다.
- **대조 보기:** 음성 구간마다 같은 시간의 화면 글자와 자막이 나란히 보입니다. 함께 있다고 바르게 전달됐다는 뜻은 아닙니다. 접힌 글자(`불확실`, `계속 표시`)도 펼쳐 볼 수 있습니다.
- 화면 위쪽의 **미점검·누락 의심** 안내가 있는 시간은 직접 확인해 주세요.

## 진행 순서
1. **(요청받은 영상만)** 앱을 쓰기 **전에** 평소 방식으로 점검하고, 찾은 문제를 기록지에 적습니다. 걸린 시간도 적습니다.
2. 앱으로 분석하고 검수합니다.
3. 앱이 알리지 않았지만 직접 찾은 문제를 기록지의 `놓친 문제`에 적습니다.
4. 지적과 대조 보기에서 몇 가지를 골라, 그 정보가 이 영상에서 얼마나 중요한지 `중요도`에 표시합니다.
5. 검수 화면의 **[지표 내보내기]**로 파일을 저장합니다.

## 보내 주실 것
| 파일 | 내용 | 영상 내용 포함 |
|---|---|---|
| `실증지표_….csv` | 처리·검수 시간과 건수, 앱 버전 | 없음 |
| 기록지(`record-sheet.csv`) | 직접 적은 내용 | **직접 적은 것만.** 개인정보나 영상의 문장은 꼭 필요한 만큼만 적어 주세요 |

**아래 자료에는 영상에 관한 내용이 들어 있습니다.** 따로 동의하지 않았다면 보내지 마세요. 보내기 전에 파일을 열어 내용을 확인해 주세요.

| 자료 | 들어 있는 것 |
|---|---|
| 검수 결과 CSV(`…_검수결과.csv`) | **발화, 화면 글자, 자막, 지적 사유, 영상 파일 이름** |
| 분석 상태 CSV(`…_분석상태.csv`) | 영상 파일 이름, 점검하지 못한 시간과 안내 문구 |
| 앱 데이터 폴더 | 발화와 화면 글자, 영상 파일의 경로, 분석 기록과 로그 |
