# 문서 안내

## 프로젝트 기준 문서

- [`project/product-brief.md`](project/product-brief.md): 사용자, 문제, 범위와 목표
- [`project/implementation-plan.md`](project/implementation-plan.md): 구현 결정과 기술 계획
- [`project/ui-spec.md`](project/ui-spec.md): 화면 동작 및 UI 요구사항
- [`project/screen-overview.md`](project/screen-overview.md): 화면 구성 개요
- [`project/database-design-draft.md`](project/database-design-draft.md): 구현 참고용 DB 설계 초안

제품 브리프와 화면 문서는 구현 전 작성된 요구사항 자료입니다. 현재 구현 범위와 동작은 코드와 테스트에서 확인하세요.

`database-design-draft.md`는 초안입니다. 현재 스키마와 다를 수 있으므로 코드와 테스트를 최종 기준으로 삼으세요.

## 보관 문서

초기 제품 브리프와 별도 실행 계획 스냅샷은 [`archive/`](archive/)에 보관합니다. 현재 요구사항이나 구현 상태와 다를 수 있습니다.

## 저장소에 포함하지 않는 자료

`docs/`에 있는 PDF·DOCX는 제출 자료와 외부 참고 문서이므로 Git에서 제외합니다. 배포 또는 평가에 필요한 자료는 권리와 민감정보를 확인한 뒤 별도로 선별합니다.
